# A 10.B karácsonya – algoritmusok lépésről lépésre

Interaktív weboldal 9–12. évfolyamos diákoknak az érettségi programozási tételeinek megértéséhez. A feladatok egy karácsonyi történetbe ágyazva, négy adventi hétre bontva szerepelnek.

| Hét | Feladat | Programozási tétel |
|---|---|---|
| 1. | Mézeskalács-sütés | Összegzés |
| 1. | Hóesés | Megszámolás |
| 2. | Karácsonyi vásár | Maximumkiválasztás |
| 2. | Titkos Mikulás | Eldöntés |
| 3. | Fenyőfa-vásárlás | Keresés |
| 3. | Fényfüzér | Kiválogatás |
| 4. | Karácsonyi műsor | Rendezés (buborékrendezés) |

Minden feladatnál:

- érettségi stílusú feladat és a megoldás ötlete,
- lépésenkénti animáció (előre, vissza, lejátszás, tempó, új adatok),
- mondatszerű leírás a futó sor kiemelésével, a változók aktuális értékével,
- a program kimenete („Képernyő”),
- Python-megoldás,
- ellenőrző kérdések magyarázattal.

Egy hét adventi koszorúja akkor gyullad meg, ha a hét összes kérdésére helyes válasz született. A haladást a böngésző tárolja; a lábléc „Haladás törlése” gombja nullázza.

## Használat

Az egész oldal egyetlen fájl (`index.html`), telepítés nem kell. Megnyitható közvetlenül a böngészőben, vagy közzétehető GitHub Pages-en.

Billentyűk: `→` következő lépés, `←` vissza, `szóköz` lejátszás / szünet.
